# 小六上架使用說明

在員工群組操作。同一本劇本請由同一位員工完成；文字與圖片不用固定間隔幾秒，**看到小六回覆開始收圖後，就可以連續傳指定張數**。

## 1．先傳劇本資料

複製下方格式，換成這次要上架的內容：

```text
陸總，上架《劇本名稱》
劇本：劇本名稱
人數：7
時長：12～14小時
售價：2300
類型：推理
標籤：台中獨家、頭腦風暴、雙主持互動
簡介：貼上完整的劇情簡介，可分段。
角色：角色一／角色二／角色三／角色四／角色五／角色六／角色七
```

- 人數可填 `7` 或 `6～8人`。售價是每人的整數金額。
- 角色名稱用 `／` 分隔；有角色名單時，固定人數須與角色數相符。
- 標籤、角色圖可以先不提供；缺少必填資料，小六會在發布前提醒。
- 收到「資料已保留」只代表存好，還沒上架。

## 2．標記用途，再傳封面

先傳：

```text
接下來這張是《劇本名稱》的封面
```

看到收圖提示後，傳 **1 張封面**。不要把之前聊天傳過的圖當成已交件。

## 3．有角色圖再做這一步

先傳張數與劇本名稱，例如：

```text
接下來這 7 張是《劇本名稱》的角色圖
```

看到收圖提示後，連續傳 7 張角色圖。小六會核對圖上的角色名稱，逐張回報。**收滿指定張數就停止收圖。** 收圖期間請不要混傳其他用途的圖片。

看不清角色名時，小六會提供圖片編號；照它的編號回覆，例如：

```text
配對角色 3：傲慢魔女的親眷
```

封面標題看不清時，先確認真的是要用的圖片，再回覆，例如：

```text
確認圖片 1 為封面
```

編號依小六實際回報為準。角色圖不是必填；沒準備角色圖就略過本步。

## 4．全部傳完，正式上架

```text
資料傳完，直接上架
```

小六會檢查欄位、封面、張數和角色配對，發布後確認官網。**收到「已上架」及官網連結才算完成。** 如果回覆仍在同步，資料已保留，稍後傳「重試上架」。

## 常用指令

| 想做什麼 | 傳給小六 |
| --- | --- |
| 看目前收了哪些圖、還缺什麼 | `上架狀態` |
| 修改還沒送出發布的資料 | `上架資料`，下一行貼要改的欄位，例如 `售價：2500` |
| 連線或同步失敗後接續 | `重試上架` |
| 取消尚未發布的任務 | `取消上架` |
| 再看操作步驟 | `上架說明` |

已經送出發布的任務會固定內容，避免重試時發布不同版本；先用「重試上架」確認結果。取消任務不會刪除已發布劇本，也不會刪除已保存的圖片或草稿。

## 已上架的劇本，之後補角色圖

```text
陸總，補《劇本名稱》的角色圖
```

接著依步驟 3 標記張數、傳圖，最後傳「資料傳完，直接上架」。更換封面可改說 `陸總，更換《劇本名稱》的封面`，再依步驟 2、4 操作。

若小六提醒同名劇本、既有未發布草稿，或舊資料尚未匯入，請交由管理員確認；不要換個名字重複上架。

## 避免誤上架的重點

- 同一位員工、同一個群組完成同一本；先完成或取消，再處理另一本。
- 一般聊天不會拿來修改上架資料。要補資料請使用欄位格式；要收圖片先標記用途與張數。
- 收圖期間傳錯圖，尚未發布時可取消任務重新整理，不要把錯圖硬配成另一位角色。
- 圖片接受 JPG、PNG、WebP，每張不超過 8 MB。
- 已成功保存的資料與圖片不會因小六重新啟動而消失。尚未存好的圖片請先傳「重試上架」；只有 LINE 原圖已過期、持續無法下載時，才需要「取消上架」，重新建立任務、標記用途並傳圖。
